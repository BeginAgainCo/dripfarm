| 2026-06-04 | **Dress the real person, not an avatar.** The base is the actual user under showroom conditions. Trust of "that's me" is the product. |
| 2026-06-04 | **Quality budget goes to the base layer.** A chained base pipeline with a quality gate; nothing composites onto an un-graduated base. |
| 2026-06-04 | **Overlays are simple pixel layers first.** Registered per-layer overlays, not cloth simulation or generative re-render. Earn fancy later, per layer. |
| 2026-06-04 | **Fixed compositing order is the product.** Back hair · base · garment stack · front hair · face. Any layer swaps without touching the others. |
| 2026-06-04 | **Hair is two layers, front and back, bracketing the garment stack.** This is what makes outfits read as worn, not pasted. |
| 2026-06-04 | **A garment owns an array of wear variants.** Styling picks garments, orders them, and picks how each is worn. |
| 2026-06-04 | **Engine choices are deferred.** Base pipeline and overlay renderer are roles to be filled during Phase 1, not products we've committed to. |

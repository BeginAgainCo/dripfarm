**Open**{.badge .open} · How idealized is the base allowed to be? Showroom lighting, yes — but reshaping, smoothing, and "improving" the person is an undrawn line that touches trust and identity. See [The Base Layer](#base).

**Open**{.badge .open} · Which engines fill the base pipeline's roles? Background removal, cleanup/relighting, pose-and-framing normalization, and the quality gate are roles, not chosen tools. Phase 1 exists to answer this.

**Open**{.badge .open} · Does the face layer need to split, the way hair did? Makeup sits on the face cleanly; glasses, earrings, and other face-adjacent accessories may need their own front/back placement relative to hair.

**Open**{.badge .open} · How are garments registered to the base so an overlay lands in the right place across poses? The whole overlay model assumes a dependable mapping from garment to body. The simplest version that holds up is still unknown.

**Open**{.badge .open} · What's the smallest set of wear variants worth modeling per garment? "Every way a shirt can be worn" is unbounded; the useful subset is not yet defined.
